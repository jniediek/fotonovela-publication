# Fotonovela figure scripts

The scripts in this repository reproduce the figures in the publication

**Episodic memory consolidation by reactivation of human concept neurons during sleep reflects contents, not sequence of events**.

## How to reproduce figures

This repository is maintained with `uv`. After cloning the repository, run `uv sync` in the repository root.

The plots are produced by Python scripts. The same scripts also store statistical test results in CSV files along each figure. 

To produce a figure, run `uv run python scripts/plot_fig_....py`.

## Where is Figure 1?

Figure 1 is not produced by a script, it is stored in `materials/fig_01.pdf`.
